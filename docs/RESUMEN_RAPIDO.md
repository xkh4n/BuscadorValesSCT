# Resumen Rápido - Buscador de Comprobantes SCT v1.3.3

> **Para usuarios que necesitan una referencia rápida**

---

## 🚀 Cómo Buscar un Comprobante

### 1. Complete los campos
- **📅 Fecha:** Use el calendario para seleccionar la fecha
- **💳 Tarjeta:** Últimos 4 dígitos (ej: `6018`)
- **💰 Monto:** Sin signos especiales (ej: `18990` o `18.990`)

### 2. Haga clic en "BUSCAR"
- Espere a que aparezca el resultado
- Si encuentra algo, verá el comprobante completo

### 3. Si hay múltiples resultados
- Aparecerán botones **◀️ ANTERIOR** y **SIGUIENTE ▶️**
- Úselos para navegar entre los comprobantes encontrados
- El label muestra "Vale X de Y"

### 4. Para buscar más en el archivo
- Use el botón **"SIGUIENTE"** (sin flechas) arriba
- Repita hasta que ya no haya más

### 5. Guardar
- Clic en **"GUARDAR"**
- Elija dónde guardar el archivo
- ¡Listo!

---

## ❓ Preguntas Rápidas

### No encuentra mi comprobante
- ✅ Verifique la fecha
- ✅ Confirme los últimos 4 dígitos
- ✅ Revise el monto exacto

### ¿Qué es el botón "SIGUIENTE" vs "SIGUIENTE ▶️"?
- **SIGUIENTE** (arriba): Busca **más** comprobantes en el archivo
- **SIGUIENTE ▶️** (abajo): Muestra el **siguiente** vale ya encontrado

### ¿Cómo diferenciar comprobantes iguales?
- **Hora:** Cada transacción tiene hora diferente
- **Nº de Operación:** Cada una tiene número único

### ¿Dónde se guarda el archivo?
- Usted elige la ubicación al guardar
- Se sugiere una carpeta como `C:\Comprobantes\`
